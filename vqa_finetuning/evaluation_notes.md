# 후속 행동 평가 시 모델 설정

이번 시작점은 사용자가 선택한 공식 `openvla/openvla-7b`다. 저장소의 기존
`scripts/eval_openvla.sh` 기본 모델인 `gen-robot/openvla-7b-rlvla-sft_16k`와 다르다.
VQA 학습의 효과를 분리하려면 동일한 공식 원본의 학습 전/후를 비교해야 한다.

공식 원본의 `config.json`에는 `norm_stats` 25개가 있지만 `sft` 키는 없다.
따라서 기존 스크립트의 기본 `UNNORM=sft`를 그대로 사용하면 맞지 않는다.
`bridge_orig`는 원본에 있는 키 중 하나이나, 어떤 키를 쓸지는 실제 로봇/제어
환경과 맞춰 결정해야 한다. 이번 VQA 데이터에는 action이 없어 새 action
정규화 통계를 만들 수 없으며, 임의로 `sft` 키를 추가하거나 다른 통계를
복사하지 않았다. 최종 merged 모델은 원본 통계를 그대로 보존한다.

공식 원본과 기존 rlvla 모델은 로봇 적응 이력도 다르므로, 기존 모델 대비
성공률 차이 전체를 VQA 학습의 효과로 해석하면 안 된다. VQA-only 학습에서
행동 능력 유지나 의미 지시 성공률 개선은 아직 측정하지 않았다.

서버의 기존 환경인 Transformers 4.47.0 / tokenizers 0.21.4를 사용했다.
공식 custom model 코드는 권장 버전 4.40.1 / 0.19.1과 다르다는 안내를 출력한다.
정확한 실행 환경은 `environment.txt`에 기록했다. 후속 평가에서는 동일 환경
및 모델별 생성/행동 인터페이스 호환성을 함께 확인해야 한다.
